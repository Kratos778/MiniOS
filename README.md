# MiniOS

Desktop estilo PC dentro de um APK Android.

| | |
|---|---|
| **Package** | `com.minios.elizierdias` |
| **Debug** | `com.minios.elizierdias.debug` |
| **Versão** | 0.1.0 |

## O que funciona

- Desktop **landscape**
- **Wallpaper**: 4 gradientes **ou foto da galeria**
- Janelas (mover, redimensionar, min/max/fechar)
- Taskbar + Start Menu
- Apps: Files, Terminal, Settings, Software Center
- **Mouse virtual** (estilo Winlator):
  - Ponteiro **acima do dedo**
  - Toque curto = clique **esquerdo**
  - Toque longo = clique **direito**

## Wallpaper de foto

1. Abre **Settings**
2. **Escolher foto da galeria**
3. A foto preenche o ecrã em landscape
4. Para voltar ao gradiente, toca num dos 4 quadrados de cor

## Build

Push na `main` → GitHub Actions gera o APK debug.
